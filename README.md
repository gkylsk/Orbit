# Orbit

A small 2D space game built with Unity and C# where the player pilots a spacecraft between planets using planetary gravity and orbital movement.

## Gameplay

Control the spacecraft and use the gravity of planets to change its trajectory and reach the target planet.

The spacecraft can:

* Move through space
* Enter a planet's gravitational influence
* Orbit around planets
* Transition from one planetary orbit to another
* Reach designated target planets to complete a level

The game focuses on simple gravity-based movement and timing rather than traditional direct movement.

## Features

* 2D planetary gravity system
* Orbital spacecraft movement
* Planet-to-planet traversal
* Target-based level progression
* Custom pixel-art spacecraft and planets

## Built With

* **Unity**
* **C#**
* **2D Physics / Custom Gravity Logic**
* **Pixel Art**

## Running the Project

1. Clone the repository.
2. Open the project using Unity Hub.
3. Open the main game scene.
4. Press **Play** in the Unity Editor.

[The game is also available on itch.io.](https://gkylsk.itch.io/orbit)

## Development

Orbit was created as a small independent Unity project to explore 2D gameplay programming, gravity-based movement, orbital mechanics, and creating a complete playable game with custom-made pixel art.
